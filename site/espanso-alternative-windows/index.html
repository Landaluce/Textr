An Espanso alternative for Windows that isn't a YAML file

You installed Espanso, opened a match file, and closed the editor. Textr is a normal Windows app: add a snippet in a window, type its trigger in any program, get the text. No Python, no terminal, no config syntax to learn.

Textr.exe needs no installer and no admin rights. Windows 10 or later.

What the window actually gives you

  • A searchable table of every snippet — grouped by folder, type or tag, with a second grouping level if you want it.
  • An editor with a live preview, so you see the expansion before you save it.
  • Enable/disable per snippet instead of commenting lines out and remembering why.
  • Placeholders — {name}, {date+7}, {clipboard}, {cursor}, and your own custom values like {company}.
  • Four snippet types: plain text, per-language code templates, actions, and shell commands whose output is inserted.
  • Backups and a trash can — the last 10 versions of your snippet file, and deleted snippets restorable instead of gone.

Already have Espanso matches?

They still work: Library → Import Espanso file… reads your .yml/.yaml match file and turns each match into a snippet. Triggers already in your library are skipped rather than overwritten, so a second import can't undo your edits.

What Textr doesn't do

  • The .exe is not code-signed. SmartScreen shows "unrecognized app" on first launch — More info → Run anyway. That's a signing certificate we don't buy, not a warning about behaviour.
  • No cloud sync or team libraries. Snippets live in %APPDATA%\Textr as JSON you can back up yourself.
  • Espanso import is partial: forms, scripts and hub packages don't transfer, and {{variables}} arrive as literal text.
  • No mobile or browser app — this is a desktop expander only.
